2. What the application does

Once a day, a backup file of a private password manager (Vaultwarden) is created and uploaded to a folder in the operator’s own Google Drive. Backups older than 14 days are deleted from that folder. If needed, a backup is restored from there.

3. Access to Google Drive

The application uses only the drive.file scope. It can therefore only see, create and delete files it created itself. It has no access to any other files in Google Drive, and it does not read contacts, emails or other account information.

4. Contents of the backups

Password manager entries are encrypted on the user’s device with their master password before they reach the server. The backup file contains these entries only in encrypted form. Neither Google nor the server can read them without the master password.

5. No sharing

No data is shared with third parties, sold, or used for advertising. Data moves only between the operator’s home server and their own Google account. Storage in Google Drive is subject to Google’s privacy policy: policies.google.com/privacy.

6. Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/connections, after which the application can no longer upload anything. Existing backups are in the “Vaultwarden-Sicherung” folder in Google Drive and can be deleted there at any time.
